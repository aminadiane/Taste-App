# Standing rules

- Never use the degree symbol or ordinal indicator (°, º, ª) anywhere, in any project. Write numbers as "N 001", never "Nº 001".
- "Cultural Capital" wordmark is always cobalt blue (--ref-cobalt #2E5BD6).
- Pallas and Cultural Capital wordmarks: Archivo, semibold/medium. Pallas title and header corner link in Archivo Expanded; the smaller Cultural Capital mark in a slightly narrower cut.
