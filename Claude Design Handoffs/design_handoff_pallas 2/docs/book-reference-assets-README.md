# Taste — Vintage Paperback Reference Assets

A curated set of individual PNG crops from the approved AI-generated vintage-paperback reference sheet. The same deep violet, worn paperback and warm-ivory paper styling carries across the views. No printed text has been introduced.

## IMPORTANT — Resolution and usage

These are **design references**, not independent original 4K studio photographs. The source image is 1536 x 1024 pixels in total. Individual images were cropped from it and enlarged using standard Lanczos interpolation plus slight sharpening for easier placement in Claude Design; this does not create genuine high-frequency 4K detail. Keep this in mind if enlarging these assets for a public, high-resolution website. For production, render or photograph each view separately at source resolution of 4000+ pixels and confirm consistency between views. 

The 00_ source file is the original unmodified complete reference sheet.

All backgrounds originate from the composite's neutral white studio setting. The macro images are reference textures, not seamless repeating tile textures. Views are artistically consistent, but do not assert geometrically exact same-object continuity.
